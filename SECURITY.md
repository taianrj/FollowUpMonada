# Política de Segurança

Não publique vulnerabilidades, credenciais, mensagens, números de telefone ou outros
dados pessoais em issues públicas.

Relate vulnerabilidades pelo recurso **Private vulnerability reporting** do GitHub na
aba **Security** deste repositório. Inclua uma descrição do impacto, passos mínimos de
reprodução e a versão ou commit afetado, sem anexar dados reais de produção.

Credenciais potencialmente expostas devem ser revogadas antes de qualquer investigação
pública. O projeto não aceita segredos em query strings, arquivos versionados, logs ou
variáveis `NEXT_PUBLIC_*`.
